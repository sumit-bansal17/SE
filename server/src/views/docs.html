TIET-Sync Academic API Reference

Comprehensive REST endpoints for student-professor consultation scheduling, classroom directory, master timetables, and academic workstations.

Base URL: http://localhost:{{PORT}}/api • Auth: Bearer JWT / HTTP-only Cookie
AVAILABLE API MODULES & ROUTES
Method Route Access Description
GET /api/health Public Server and database health status
POST /api/auth/login Public User authentication (JWT issued in cookie & payload)
POST /api/auth/register Students Self-registration with Thapar university email
GET /api/auth/me Authenticated Current logged-in user profile & role
GET /api/professors Authenticated Faculty directory with search & department filters
GET /api/classrooms Authenticated Classroom & lab directory with block/type filters
GET /api/timetable/me Authenticated Current user's 13-period weekly timetable
GET /api/requests/mine Student Student's consultation requests & tracking
GET /api/requests/incoming Professor Incoming consultation booking requests
GET /api/resources Authenticated Academic resource documents & shared notes
GET /api/workspace/files Authenticated Personal workspace storage files (20 MB quota)
GET /api/admin/audit-logs Admin Chronological institutional audit trails
